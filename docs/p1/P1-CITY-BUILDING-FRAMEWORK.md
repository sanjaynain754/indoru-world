# P1 City Building Framework

The next Indoru layer connects residential buildings to a real city structure.

Pipeline:
Terrain -> Roads -> City Blocks -> Plots -> Utilities -> Buildings -> Interiors -> NPC access -> Traffic -> World Partition.

Navaar is the first vertical-slice target. The framework supports local, collector, arterial and highway roads plus twelve core city zones.

This is a construction/data foundation, not finished AAA art. UE5 production will supply terrain, meshes, materials, interiors, traffic splines, navmesh, lighting, VFX and audio.
