# Memory

- The source repository is `sanjaynain754/indoru-world`; an earlier configured name `Kaam24` returned 404.
- The original repository contains a C++ physics foundation. This WebDev project is the first browser-playable presentation layer and keeps the C++ code as the core-engine reference.
- Babylon is loaded from `@babylonjs/core` deep imports. Keep React out of gameplay modules.
- WebDev preview runs on port 3000. Use `?demo` for deterministic visual QA.
- Generated images must stay outside the project tree and be referenced through managed `/manus-storage/...` URLs.
